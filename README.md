# Machina Hnos · App Android

Prototipo nativo Android para catálogo y precalificación de interesados en vehículos.

## V0.1
- Kotlin + Jetpack Compose.
- Catálogo DEMO.
- Buscador.
- Filtros Auto / SUV / Pickup.
- Ficha del vehículo.
- Favoritos.
- CTA `QUIERO ESTE AUTO`.
- CTA `HABLAR CON UN ASESOR`.
- Punto preparado para integrar Chatbox y pasar el vehículo seleccionado.

Los datos actuales son ficticios hasta recibir stock, identidad visual y reglas comerciales del cliente.

## Abrir
1. Clonar el repositorio.
2. Abrir la carpeta raíz en Android Studio.
3. Esperar Gradle Sync.
4. Ejecutar en emulador/dispositivo Android.

## Arquitectura prevista
App Android → Chatbox/API → calificación → asesor/WhatsApp.
